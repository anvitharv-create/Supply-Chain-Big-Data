# Supply Chain and Inventory Analysis Using Big Data Analytics

## About the Project

This is my Big Data Analytics project based on supply chain and inventory data.

The main idea of the project is to understand how products, warehouses, suppliers, sales, and inventory are performing. I used PySpark to process the data and Spark SQL for some of the analysis. The processed results are then shown through a Streamlit dashboard.

The project takes the data from a raw CSV file, cleans and validates it, creates some additional fields for analysis, stores the processed data in Parquet format, and then performs different types of supply chain analysis.

## What I Worked On

The project covers the following areas:

- Data ingestion using PySpark
- Data validation and duplicate checking
- Feature engineering
- Parquet data storage
- Product analysis
- Warehouse analysis
- Supplier analysis
- Regional analysis
- Reorder analysis
- Spark SQL queries
- Interactive Streamlit dashboard
